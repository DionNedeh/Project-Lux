Extreme shaping flexibility — TCV can produce plasma cross-sections no other machine can, which is why it is the world's reference device for shape-dependent physics including Negative Triangularity.

Why it matters beyond shaping#

This is where DeepMind demonstrated deep-reinforcement-learning magnetic control (Nature, 2022): a single RL agent commanded all 19 shaping coils directly, achieving configurations that would otherwise have required bespoke controller design for each. The first serious demonstration that learned controllers can run a real tokamak.

TCV is also a principal site for Neoclassical Tearing Mode (NTM) pre-emption using electron cyclotron current drive, and for sawtooth pacing studies.

EPFL's Swiss Plasma Center additionally hosts FALCON, the facility where gyrotrons for ITER and DTT — Divertor Tokamak Test are qualified.
